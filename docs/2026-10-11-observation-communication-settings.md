# 2026-10-11 視界・通信範囲の設定とデフォルト値一覧

## 変更

「世界設定」から視界と通信の範囲を個別に0〜50マスで指定できるようにする。既存の `view_range` / `message_range` を画面から渡し、従来の `Simulation` と保存処理を使用する。実験エンジン・保存形式・HTTP経路は追加しない。

既定値は従来どおり視界2、通信3。範囲は斜めを含む正方形で、世界は周期境界。半径が世界の一辺の半分（端数切り捨て）以上なら全体に届く。設定値は世界を縮小しても維持し、実際に覆う広さを世界の一辺までに制限して表示する。画面で指定できる世界の最大一辺100に合わせ、範囲の最大値を50にした。

視界は体力共有にも適用される。通信は発言の配送範囲で、受信内容は次のターンに読まれる。0は通信の無効化ではなく同じマスだけを対象とする。攻撃は従来の上下左右の隣接1マスを維持する。

READMEにはアプリ初回の全設定値、固定ルール、CLIとの初期条件の違いを記載する。既存のユーザー編集（表情・砂糖・個体IDの説明）はそのまま保持する。

## 世界観プリセットの採用方針

ユーザーが採用した案は「お菓子の楽園」「最後のオアシス」「助け合いの村」の3つ。「生存競争の荒野」は、繁殖をしなくなって面白くならないと予想されるため採用しない。

「最後のオアシス」は砂糖を少なく・一部に集中させるだけでは、個体から砂糖が見えず、通信も届かずに観察したい状況が生まれない可能性がある。今回追加する範囲設定を使って条件を調整する。3案の数値・世界観文は今回確定せず、プリセット選択肢の実装は条件の調整後に行う。
