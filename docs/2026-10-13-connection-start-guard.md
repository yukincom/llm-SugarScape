# 接続できない場合の開始中止

preview.33では、LLM/APIを使う実験の開始前に接続先へHEADを送り、接続できない場合は「接続できません」と表示して開始を中止する。実験の記録を作成せず、ターン・判断・翻訳も実行しない。接続確認は設定されたタイムアウト以内、最大5秒で終了する。

既存の生成先 `/chat/completions` を確認するため、別のAPIエンドポイントへの対応は要求しない。HEADに非対応の404/405などもHTTP応答が届けば接続可能として扱う。モデル生成は依頼せず、認証・モデル設定の判定や実験中のエラー処理は従来どおり。手動の接続テストとMockの動作も変更しない。

検証対象は接続拒否・タイムアウト時の開始中止、記録や生成が作られないこと、画面のエラー表示、接続確認中の停止、HEAD非対応サーバーとMockの互換性。実LLMへの生成依頼は行わない。

全157テストに合格（外部接続を遮断）。専用のローカル接続でも、接続拒否時は記録・ターン・判断が0件、HEADが405でも接続できるサーバーでは通常の実験処理に進むことを確認した。開始後の通信エラーの扱いは既存のテストで確認した。
