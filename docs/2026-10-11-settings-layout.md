# 2026-10-11 設定欄とドキュメントの整理

- 「LLM設定」を既定で閉じた折りたたみ欄に変更。接続先・モデル・APIキーと、既存処理を使う「接続テスト」を同じ欄へまとめる。
- 「実験を選ぶ」を「実験設定」に変更する。
- 実験全体のターン数・乱数シードを外に置き、「エージェント設定」「砂糖設定」「世界設定」を個別の折りたたみ欄に分ける。生成条件は「LLM設定」、盤面画像の保存は実験全体へ移動する。
- 砂糖の「適用」ボタンを削除。選択中の砂糖の量を、実験開始時に他の設定とまとめて渡す。重複していた詳細設定の初期砂糖数の入力欄は取り除き、砂糖の量の選択を唯一のUI入力とする。
- 実験画面と保存一覧のサンプルボタンを削除。READMEには利用者提供の `img/apri.mov` と、85秒時点から抽出したプレビュー画像を使う。既存の説明用サンプル記録はリポジトリの表示確認用に残し、配布アプリには同梱しない。
- アプリ内の「使い方」を削除し、利用者向けの操作説明をREADMEへ統合。準備・接続・設定・結果の順に並べ、表で整理する。開発手順と詳細仕様は利用者指定の `agent.md` に分け、重複する `USER_GUIDE.md` は削除する。
- 判断生成回数の上限見積もりは表示しない。人口上限の説明を「人口上限に達すると繁殖が止まります」にする。
- 人口上限による実験の自動終了は元から存在しない。現行の終了条件（指定ターン数、または全員死亡）は変更しない。
