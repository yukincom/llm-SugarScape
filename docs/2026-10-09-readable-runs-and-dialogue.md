# 2026-10-09 読みやすい保存先と発言表示

## フォルダ名

保存先を `日本時間の年月日_時分秒_モデル名` に変更した。例：`2026-10-09_14-54-55_Qwen3.5-2B-6bit`。同じ秒・モデルで再実行した場合は `_02`、`_03` と連番を付け、既存フォルダを上書きしない。Mockはモデル名部分を `Mock` とする。

JSON/CSVの結合に使う内部 `run_id` は従来どおり一意の値を保持する。フォルダ名と内部IDを分離したため、保存先を読みやすくしても既存記録の参照関係は変わらない。schema 2とシミュレーションのルールを維持した。

ユーザーが指定した完了済み実験のフォルダも変更した。

- 変更前：`outputs/20261009T055455106547Z_0_f74bc882/`
- 変更後：`outputs/2026-10-09_14-54-55_Qwen3.5-2B-6bit/`

manifest、journal、CSVのSHA-256が移動前後で一致すること、84件のイベントが残ることを確認した。`run.json` は `output_dir` だけを更新した。画面に旧パスの結果が残っている場合は、同じ親フォルダから内部IDが一致するmanifestを見つけて表示を継続する。旧名への互換リンクがある場合は実体の保存先を表示し、集計も同じ実体を一度だけ数える。

## 発言と行動理由

保存済みの `message` と `thought` を表示に使う。別の推論要求や会話データの保存経路は追加していない。

- 応答が届くたび、ターミナルにステップ・個体・選択した行動・発言・行動理由を表示する。
- Streamlitは実行中に直近10件を表示する。この時点の行動は適用前の選択である。
- 終了後は「エージェントの会話」でステップ・個体を選択できる。実際に適用した行動、エネルギー変化、発言を表示し、行動理由は展開して読める。
- 応答エラーや拒否した行動も状態を表示する。発言が空なら「発言なし」とし、表示用の台詞は作らない。
- 進捗ログの判断数は `decisions_this_step` と `decisions_total` に分けた。

表示コールバックには応答のコピーを渡す。全個体の判断を集めてから行動を適用する既存の順序は保つ。
