# 2026-10-09 デスクトップ版の実験保存先

ユーザー指定により、preview.4から実験の既定保存先を `.app` と同じフォルダ内の `outputs` にする。既存の `SUGARSCAPE_OUTPUT_DIR` と画面の「保存先」を利用し、保存処理を増設しない。アプリの署名対象であるバンドル内部には書き込まない。

- 配布版: `<アプリを置いたフォルダ>/outputs`
- ソースからの起動: `<リポジトリ>/outputs`
- `SUGARSCAPE_OUTPUT_DIR` を指定した場合はその値を優先する。
- 起動ログ・描画キャッシュは従来のApplication Support配下に置く。`SUGARSCAPE_DATA_DIR` はこの内部データの親を指定する。
- 旧版の実験を自動移動・削除しない。以前の保存先を選ぶか、記録をコピーして読み返せる。

配布版・ソース実行・保存先の明示指定を確認するテストを追加し、56件の自動テストが成功した。これは保存先変更のソースチェック時点の記録であり、この後に行うプロンプト復元と配布ビルドの検証は別に記録する。

preview.4の配布版で `dist/desktop/outputs` が初期表示されることを確認。旧保存先の18:15のHuihui Gemma実験を同フォルダへコピーし、7ファイルすべてのSHA-256一致とアプリからの再生を確認した。元フォルダは残している。[復元と最終検証](2026-10-09-paper-protocol-restoration.md)も参照。
