# Board icons

The hexadecimal filenames are unmodified 72×72 PNG artwork from [Twemoji v17.0.3](https://github.com/jdecked/twemoji/tree/v17.0.3/assets/72x72).

Copyright Twitter, Inc. and other contributors. Graphics are licensed under [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/); see `LICENSE-GRAPHICS`.

`sources.json` records each original URL and SHA-256. Images are bundled for offline rendering; drawing scales them without modifying the asset files.

`candy-pink.png` is the custom pink resource icon generated with the built-in image generation tool, then resized to 72×72 with alpha preserved. Its original is `../artwork/candy-pink-original.png`; the prompt and verification are in `../../docs/2026-10-09-pink-candy-icon.md`. It is separate from the Twemoji artwork. The red Twemoji `1f36c.png` is retained as an unused original.
